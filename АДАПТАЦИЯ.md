# Адаптация каталога «Пункт»

Исходная версия получена из ветки `feat/hero-interface` репозитория `nacky-design/PUNKT` (коммит `c256858`). Каталог вынесен на главную страницу, подробная карточка — на отдельный экран с адресом вида `#car/1`. Дополнительный подбор доступен из карточки по кнопке «Изменить параметры». На главной можно выбрать класс и пробег, а условия доставки открываются по ссылке в баннере.

Запуск: `npm ci`, затем `npm run dev`. Проверка сборки: `npm run build`.

Это демонстрационный прототип: данные автомобилей и цены взяты из исходной версии, наличие не проверяется, а форма заявки не отправляет данные. Перед коммерческим запуском необходимо подключить реальные данные и отправку заявки, а также проверить конфигурацию путей и сборки для выбранного хостинга.
