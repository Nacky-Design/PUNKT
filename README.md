# Пункт — демонстрация сайта проката автомобилей

Адаптивный прототип сайта проката: каталог и поиск автомобилей, страницы машин и услуг, тарифы, условия аренды и демонстрационный личный кабинет.

## Запуск

Требуется Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

Для сборки выполните `npm run build`. Готовые файлы находятся в `dist/`; относительные пути позволяют разместить их в подпапке GitHub Pages.

## Демо-режим

Тарифы и условия в каталоге взяты из согласованного прайса. Сайт рассчитывает предварительную стоимость аренды и показывает параметры для звонка. Личный кабинет работает в деморежиме. Вход по паролю и СМС не проверяет данные, а отправка онлайн-заявок и интеграция с CRM требуют серверной части.

Карточки Solaris, Coolray и Creta используют фотографии из автопарка. Часть остальных карточек использует [демонстрационные изображения](docs/demo-photos.md).
