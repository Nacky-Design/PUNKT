# Пункт — интерактивная концепция

Рабочий главный экран по утверждённой композиции: Vue 3, TypeScript, Vite. Брендовые цвета `#FFC107` / `#171717`, локальный шрифт Golos Text.

## Запуск

Нужен Node.js 22.12+ (проверено на 24.22.1).

```sh
cd /workspace/PUNKT
npm ci --cache /tmp/punkt-npm-cache
npm run dev -- --port 5173
```

UI kit: откройте `/?ui-kit`. На основном экране оставлен только HERO, без нижних блоков и футера. Сборка: `npm run build`. Проверка production-сборки: `npm run preview -- --port 4173`.

## Что работает

- Прозрачная навигация поверх сцены, светлая адаптация логотипа с жёлтым акцентом и мобильное меню.
- Отдельный полупрозрачный виджет доставки справа сверху.
- HERO на всю высоту окна desktop; верх панели фиксирован при открытии/закрытии быстрого выбора. На мобильных предусмотрена прокрутка содержимого.
- Класс автомобиля, даты с проверкой диапазона, место получения, пакеты пробега, Защита+, доставка и контекст арендатора.
- Независимый быстрый выбор: фильтры, горизонтальная карусель, раскрытие без изменения высоты HERO.
- Результаты подбора, сортировка и пустое состояние в модальном окне, без добавления секций под HERO.
- Карточка машины, переключение галереи, предварительная разбивка стоимости.
- Валидация имени, телефона и согласия. Корректный демонстрационный результат без фиктивной отправки.
- Модальные окна акции, услуг, условий, новостей и входа в кабинет; закрытие Escape, удержание и возврат фокуса.
- Hover, focus, pressed, disabled, error; поддержка reduced motion.

## Границы текущего этапа

Это frontend-прототип, не опубликованный сервис. Нет backend, реальной отправки, SMS, авторизации, хранения персональных данных, реального наличия автомобилей и оплаты. Кнопка кабинета показывает предварительный состав и статус, не выполняет вход. Содержание отдельных разделов показано в модальных окнах: полноценные страницы вне текущего этапа.

Шесть автомобилей и тарифы — демонстрационные. Базовые примеры Solaris/Rio/BMW/Camry взяты из нового ТЗ; кроссоверы, надбавки 700/1500 ₽ за пробег и 490 ₽ за «Защита+» нужны только для демонстрации расчёта. Они не являются утверждёнными тарифами. Залог и доставка не входят в пример итога; это явно указано. Количество суток считается по календарным датам; часы и бизнес-правила расчёта нужно уточнить до интеграции.

Акция доставки — анонс без утверждённой даты/территории. Дата «10 января» не опубликована, бесплатная доставка не включается автоматически. Документы не загружаются через сайт. Действующий юридический PDF, политика, реквизиты, ссылки на мессенджеры и данные реального автопарка ожидают подключения.

Фон — временная сгенерированная фотография. Видеофайла пока нет. Галерея использует общий вид и два увеличенных фрагмента того же изображения; это отмечено в карточке. Для запуска нужны настоящие фотографии с разных ракурсов.

## Проверки

```sh
npm run build
npm test
```

Playwright использует `/usr/bin/chromium`. При другом расположении: `CHROMIUM_PATH=/путь/к/chromium npm test`. Проверяются календарь, фильтры, расчёт, валидация, фокус модальных окон, галерея, карусель, отсутствие горизонтального переполнения, видимость всех опций и неизменная высота HERO на 320 / 430 / 768 / 1024 / 1440 / 1536 / 2048 px.

## Материалы

Логотип извлечён из клиентского `PUNKT_Technical_Specification.docx` и используется как растровый источник с CSS-компоновкой, без перерисовки. Для production нужен оригинальный SVG.
