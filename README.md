# Пункт — демонстрация сайта проката автомобилей

Адаптивный прототип сайта проката: каталог и поиск автомобилей, страницы машин и услуг, тарифы, условия аренды и демонстрационный личный кабинет.

## Запуск

Требуется Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

Для сборки выполните `npm run build`. Готовые файлы находятся в `dist/`; относительные пути позволяют разместить их в подпапке GitHub Pages.

## Демо-режим

Цены, бронирование, фотографии автомобилей и данные личного кабинета приведены для демонстрации. Вход по паролю и СМС не проверяет данные; заявки, запросы, письма, СМС и фотографии не отправляются. Для рабочего запуска нужны серверная часть, подтверждённые сведения об автомобилях и условиях, подключение мессенджеров и других сервисов.

Иллюстрации автомобилей и портрет созданы для макета; подробности об изображениях автомобилей — в [docs/demo-photos.md](docs/demo-photos.md).
