# Демонстрационные изображения автомобилей

Изображения созданы встроенным генератором изображений. Задний ракурс создавался с использованием соответствующего переднего ракурса как референса. Изображения демонстрационные и не являются фотографиями фактического автопарка.

Набор запросов: фотореалистичное изображение указанной модели и цвета для каталога проката; автомобиль целиком, вид спереди под углом; современная площадь в Москве, серое покрытие, мягкий тёплый свет на закате, слегка размытая архитектура, без людей, водяных знаков и читаемых номеров. Для заднего ракурса: тот же автомобиль по референсу, вид сзади под углом, сохранить цвет, поколение, пропорции, колёса, освещение и окружение.

Файлы сжаты в WebP; для каталога созданы отдельные уменьшенные версии.
